# FaceTransformN8N

This repository contains one n8n community node for the Ace Data Cloud Face Transform service. Use Node.js 24 and pnpm 11. Run `pnpm install --frozen-lockfile`, `pnpm run build`, `pnpm run lint`, and `pnpm test`. Keep strict mode, no runtime dependencies beyond the n8n peer dependency, and no automatic retry of paid API calls. Do not read local files or environment variables in node runtime code. Examples and screenshots must contain no credentials. Deliver changes through PRs under the Ace Data Cloud Dev bot identity.
