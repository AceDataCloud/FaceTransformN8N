# Contributing

Use Node.js 24 and pnpm 11. Run `pnpm install --frozen-lockfile`, `pnpm run build`, `pnpm run lint`, and `pnpm test`. Unit tests mock the HTTP boundary and do not charge for API calls. Never add API tokens or identifiable portrait data to commits. Submit changes through a PR with contract, test and example updates. Keep this package limited to Face Transform and free of runtime dependencies.
